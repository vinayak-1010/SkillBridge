SkillBridge

A reliable local agent harness for small open-weight models

View on GitHub ↗

SkillBridge lets tiny open-weight models (1-4B parameters, run locally through Ollama) execute standard Agent Skills reliably — constrained decoding, progressive skill loading, and a verify-and-retry loop. No GPU. No paid API.

This page is a static frontend. It talks to a SkillBridge API that runs locally on your machine, next to Ollama — nothing here is a hosted cloud model. See running the web demo to start your own API.
